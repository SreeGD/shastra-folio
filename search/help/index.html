Search syntax

The search box accepts plain words, exact phrases, prefix wildcards, and boolean operators. Diacritics and Sanskrit aliases are handled automatically. Examples on this page use universal terms (kṛṣṇa, dharma, yoga…) so they work against any of the 22 integrated works.

Plain words

QueryMatches
karmaverses containing karma (or any stemmed form: karmic, karmaṇi)
karma yogaverses containing both karma AND yoga (default: AND)
krsnaalso matches kṛṣṇa, krishna, kr̥ṣṇa — diacritics + aliases handled

Phrases

Wrap an exact phrase in quotes. Order matters.

QueryMatches
"sarva-dharmān parityajya"verses with that exact phrase (BG 18.66)
"aham brahmāsmi"verses with the exact phrase
"karma yoga" arjunaphrase plus standalone word — both required

Wildcards

Use * at the end of a word for prefix matching. Wildcards inside or at the start of a word aren't supported.

QueryMatches
medit*meditate, meditation, meditating, meditator…
devotion*devotion, devotional, devotionally…
yog*yoga, yogī, yogic, yogeśvara…

Boolean operators

By default, multiple words are joined with AND. Use + to require a term and - to exclude one.

QueryMatches
karma yogaAND (default) — both required
+karma +yogaexplicit AND — same as above
karma -kāmakarma but NOT kāma (the wrong-vowel false-match)
krishna -arjunakṛṣṇa-without-arjuna verses

Diacritics and Sanskrit aliases

You can type Sanskrit names with full IAST diacritics or without — both find the same verses. The search index normalises diacritics and applies a small alias map for common spellings:

TypeAlso matches
krsnakṛṣṇa, kr̥ṣṇa, krishna
caitanyachaitanya
visnuviṣṇu, vishnu
sivaśiva, shiva
vrindavanvṛndāvana, vrndavana
radharādhā

Where the search looks

Each verse document is indexed over several fields, each with a relevance boost. A hit in ref (e.g. typing BG 2.47) ranks above a hit in synonyms:

FieldBoostNotes
ref×5Verse reference like BG 2.47, SB 10.14.4
translation×3English verse translation
iast×2Sanskrit verse in IAST transliteration
purport×2English purport / commentary
synonyms×1Word-for-word Sanskrit → English glossary
guidance×1Personal-guidance essence (where present)

Result facets

Once results appear, the sidebar (or top of the page on mobile) shows three facets you can click to filter:

  • Genre — Scripture, Commentary, Practice, Discourse
  • Hierarchy (work) — Filter to BG, SB, CC, ISO, NoI, …
  • Text Type — Which field matched (translation, purport, iast, …)

Bookmarkable URLs

Every search is a shareable URL with query parameters:

  • /search/?q=karma — initial query
  • /search/?q=karma&work=bg — narrow to one work
  • /search/?q=karma&genre=scripture — narrow by genre
  • /search/?q=karma&field=translation — narrow by matched field

What's not (yet) supported

  • Single-character wildcards (? as in s?n) — coming later
  • OR operator (| or or) — currently the search always ANDs unless you exclude with -
  • Proximity search (within N words / N verses) — would require positional metadata; deferred for index-size reasons
  • Fuzzy / typo-tolerant matching — Sanskrit terms are precise; we lean on the diacritic + alias normaliser instead
