About This Book

This book is part of the Vidyā Karaṇa (विद्या करण) Value Education Series, designed for the Primary (Ages 6-9) age group.

Each chapter explores one of the values from the daivī sampad (divine qualities) described in the Bhagavad Gītā verses 16.1–3. The values are presented in a carefully sequenced order, where foundational values are taught before those that build upon them.

This Provenance Volume documents the sources, citations, and generation lineage for every value covered in the companion books. For each value, you will find:

  • Generation lineage — model, ontology source, corpus, verse cache, schema version
  • Verses cited — anchor verse, SB verse, and full scripture references
  • Stories — epic and modern story sources and protagonist details
  • Anti-patterns surfaced — what the value is NOT, per tradition
  • Multiple-Intelligence framework — developmental targets and HP focus
  • Verification result — fact-check pass/fail with detail per check

This document is intended for educators, parents, and reviewers who want to verify or trace the curriculum back to its sources.
