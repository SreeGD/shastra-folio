ಅಧ್ಯಾಯ ಪರಿಚಯ

ಆತ್ಮನಿಗ್ರಹ ಎಂದರೆ ನಿಮ್ಮ ದೇಹ ಮತ್ತು ಮನಸ್ಸಿನ ಒಡೆಯರಾಗುವುದು. ಬೇರೆ ಯಾವುದೋ ಮಾಡಬೇಕೆಂದು ಅನಿಸಿದರೂ ಒಳ್ಳೆಯ ಕೆಲಸವನ್ನು ಆಯ್ಕೆ ಮಾಡಿಕೊಳ್ಳಲು ನಿಮಗೆ ಸಾಧ್ಯ ಎಂಬುದು ಆತ್ಮನಿಗ್ರಹ.

ಶ್ಲೋಕ: Bhagavad-gita 6.5 — ನಮ್ಮ ಮನಸ್ಸಿನ ಸಹಾಯದಿಂದ ನಾವೇ ನಮ್ಮನ್ನು ಮೇಲೆತ್ತಿಕೊಳ್ಳಬೇಕು. ಮನಸ್ಸು ನಮ್ಮಿಂದ ಕೆಟ್ಟ ಕೆಲಸ ಮಾಡಿಸಬಾರದು. ನಮ್ಮ ಮನಸ್ಸೇ ನಮ್ಮ ಆತ್ಮೀಯ ಸ್ನೇಹಿತನೂ ಆಗಬಲ್ಲದು, ಶತ್ರುವೂ ಆಗಬಲ್ಲದು.

ಮುಖ್ಯ ಬೋಧನೆ

  1. ನಿಮ್ಮ ಮನಸ್ಸನ್ನು ನೀವು ನಿಯಂತ್ರಿಸಿದರೆ ಅದು ಸ್ನೇಹಿತ; ನಿಯಂತ್ರಿಸದಿದ್ದರೆ ಶತ್ರು.
  2. ಬೇರೇನೋ ಮಾಡಬೇಕೆಂದು ಅನಿಸಿದಾಗಲೂ ಒಳ್ಳೆಯ ಆಯ್ಕೆಯನ್ನೇ ಮಾಡುವುದು ಆತ್ಮನಿಗ್ರಹ.
  3. ನಿಮ್ಮ ಮೇಲೆ ನಿಮಗೇ ಹಿಡಿತ ಬಂದಾಗ ಒಳಗೆ ಸಂತೋಷ ಮತ್ತು ಶಕ್ತಿ ಅನಿಸುತ್ತದೆ.

ಐದು-ನಿಮಿಷ ಪರಿಚಯ

ಮಕ್ಕಳನ್ನು ಶಾಂತವಾಗಿ ಕೂರಿಸಿ ೩೦ ಸೆಕೆಂಡು ತಮ್ಮ ಉಸಿರಾಟವನ್ನು ಗಮನಿಸಲು ಹೇಳಿ. ಕೇಳಿ: 'ಈಗ ನಿಮ್ಮ ದೇಹದ ಒಡೆಯ ಯಾರು? ನೀವೇ! ಅದನ್ನೇ ಆತ್ಮನಿಗ್ರಹ ಎನ್ನುತ್ತೇವೆ — ನಿಮ್ಮ ಮೇಲೆ ನಿಮಗೇ ಒಡೆತನ.' ಒಳಗೆ ಬೇರೆ ಭಾವನೆ ಇದ್ದರೂ ಶಾಂತವಾಗಿ ಕೂರಲು, ಮೆಲ್ಲನೆ ಮಾತನಾಡಲು, ದಯೆಯಿಂದ ಇರಲು ಆಯ್ಕೆ ಮಾಡಬಹುದು ಎಂಬುದನ್ನು ತೋರಿಸಿ. ಇಂದಿನ ಕಥೆಗಳಲ್ಲಿ ಮಕ್ಕಳು ತಮ್ಮ ಭಾವನೆಗಳ ಒಡೆಯರಾಗಲು ಹೇಗೆ ಕಲಿತರು ಎಂಬುದನ್ನು ನೋಡೋಣ ಎಂದು ತಿಳಿಸಿ.

40-ನಿಮಿಷ ಪಾಠ ಯೋಜನೆ

40-ನಿಮಿಷ ಪಾಠ ಯೋಜನೆ

ಆರಂಭಿಕ ವೃತ್ತ (೫ ನಿ) → ಚಲನೆಗಳೊಂದಿಗೆ ಪ್ರಹ್ಲಾದ ಕಥೆ (೧೦ ನಿ) → ಆದಿತಿ ಕಥೆಯ ಚರ್ಚೆ (೮ ನಿ) → ಗುರಾಣಿ ಕಲಾ ಚಟುವಟಿಕೆ (೧೫ ನಿ) → ಬಲಿಷ್ಠರಾಗಿರುವ ಬಗ್ಗೆ ಸಮಾಪನ ಹಾಡು (೨ ನಿ)

ಎರಡು-ಗಂಟೆ ಪಾಠ ಯೋಜನೆ

ಆರಂಭಿಕ ವೃತ್ತ (೧೦ ನಿ) → ಪಾತ್ರಾಭಿನಯದೊಂದಿಗೆ ಪ್ರಹ್ಲಾದ ಕಥೆ (೨೦ ನಿ) → ಆದಿತಿ ಕಥೆ ಮತ್ತು ಚರ್ಚೆ (೧೫ ನಿ) → ಗುರಾಣಿ ತಯಾರಿಕೆ (೩೦ ನಿ) → ನಿಲ್ಲಿಸಿ ಉಸಿರಾಡಿ ಆಟ (೧೫ ನಿ) → ಮರಕ್ಕೆ ಬಣ್ಣ ಹಚ್ಚುವುದು (೨೦ ನಿ) → ವೃತ್ತದಲ್ಲಿ ಗುರಾಣಿಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳುವುದು (೮ ನಿ) → ಸಮಾಪನ ಹಾಡು ಮತ್ತು ಶಾಂತ ಸಮಯ (೨ ನಿ)

ಚರ್ಚಾ ಮಾರ್ಗದರ್ಶಿ

೧. ಪ್ರಶ್ನೆ: ರಾಕ್ಷಸರು ಭಯಪಡಿಸಲು ಪ್ರಯತ್ನಿಸಿದಾಗ ಪ್ರಹ್ಲಾದ ಶಾಂತವಾಗಿರಲು ಯಾವುದು ಸಹಾಯ ಮಾಡಿತು? ಮಾದರಿ ಉತ್ತರ: ಅವನು ಹೃದಯದಲ್ಲಿ ವಿಷ್ಣುವಿನ ನಾಮ ಹಾಡಿದನು; ವಿಷ್ಣು ತನ್ನನ್ನು ಪ್ರೀತಿಸುತ್ತಾನೆ ಎಂದು ನೆನಪಿಸಿಕೊಂಡನು. ೨. ಪ್ರಶ್ನೆ: ರಚ್ಚೆಯ ಬೆಳಿಗ್ಗೆಗಳನ್ನು ಆದಿತಿ ಹೇಗೆ ಬದಲಾಯಿಸಿಕೊಂಡಳು? ಮಾದರಿ ಉತ್ತರ: ಹೊದಿಕೆಯ ಕೆಳಗೆ ಅಡಗುವ ಬದಲು ಹತ್ತು ಎಣಿಸಿ ಆಳವಾಗಿ ಉಸಿರಾಡಲು ಕಲಿತಳು. ೩. ಪ್ರಶ್ನೆ: ನಿಮಗೆ ಯಾವಾಗ ನಿಮ್ಮನ್ನು ನಿಯಂತ್ರಿಸಿಕೊಳ್ಳುವುದು ಕಷ್ಟವಾಗುತ್ತದೆ? ಮಾದರಿ ಉತ್ತರ: ಸುಸ್ತಾದಾಗ, ಯಾರಾದರೂ ಆಟಿಕೆ ತೆಗೆದುಕೊಂಡಾಗ, ಬಯಸಿದ್ದಕ್ಕಾಗಿ ಕಾಯಬೇಕಾದಾಗ. ಈ ಉತ್ತರಗಳನ್ನು ಬಳಸಿ 'ಹತ್ತು ಎಣಿಸಿ ಉಸಿರಾಡಿ' ತಂತ್ರವನ್ನು ಒಟ್ಟಿಗೆ ಅಭ್ಯಾಸ ಮಾಡಿ.

ಸಾಮಾನ್ಯ ತಪ್ಪು ಗ್ರಹಿಕೆಗಳು

  • ತಪ್ಪು ಕಲ್ಪನೆ: ಆತ್ಮನಿಗ್ರಹ ಎಂದರೆ ಎಂದೂ ಕೋಪ ಅಥವಾ ದುಃಖ ಅನಿಸದಿರುವುದು. ಉತ್ತರ: ಎಲ್ಲ ಭಾವನೆಗಳಿಗೂ ಜಾಗ ಇದೆ ಎಂದು ವಿವರಿಸಿ — ಆತ್ಮನಿಗ್ರಹ ಎಂದರೆ ಆ ಭಾವನೆಗಳ ಜೊತೆ ಏನು ಮಾಡಬೇಕೆಂಬುದನ್ನು ಆಯ್ಕೆ ಮಾಡಿಕೊಳ್ಳುವುದು.
  • ತಪ್ಪು ಕಲ್ಪನೆ: ಆತ್ಮನಿಗ್ರಹ ಎಂದರೆ ಯಾವಾಗಲೂ ಪರಿಪೂರ್ಣರಾಗಿರುವುದು. ಉತ್ತರ: ಆತ್ಮನಿಗ್ರಹ ಪ್ರತಿದಿನದ ಅಭ್ಯಾಸ; ಕಲಿಯುವಾಗ ತಪ್ಪು ಮಾಡಿದರೂ ಚಿಂತೆ ಇಲ್ಲ ಎಂದು ಒತ್ತಿಹೇಳಿ.
