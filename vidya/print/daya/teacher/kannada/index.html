ಅಧ್ಯಾಯ ಪರಿಚಯ

ದಯೆ ಎಂದರೆ ಇತರರು ದುಃಖದಲ್ಲಿರುವಾಗ ಅವರ ಬಗ್ಗೆ ಚಿಂತೆ ಪಡುವುದು ಮತ್ತು ಸಹಾಯ ಮಾಡಲು ಬಯಸುವುದು. ಯಾರಾದರೂ ಅಳುತ್ತಿದ್ದರೆ ಅಥವಾ ನೋವಿನಲ್ಲಿದ್ದರೆ, ನಾವು ಅವರನ್ನು ಸಂತೋಷಪಡಿಸಲು ಪ್ರಯತ್ನಿಸುತ್ತೇವೆ.

ಶ್ಲೋಕ: Bhagavad-gita 16.2 — ಹಿಂಸೆಯಿಲ್ಲದಿರುವಿಕೆ, ಸತ್ಯವಾದ, ಕೋಪವಿಲ್ಲದಿರುವಿಕೆ, ತ್ಯಾಗ, ಶಾಂತಿ, ದೂಷಣೆ ಹೇಳದಿರುವಿಕೆ, ಎಲ್ಲಾ ಜೀವಿಗಳ ಮೇಲೆ ದಯೆ, ದುರಾಸೆಯಿಲ್ಲದಿರುವಿಕೆ, ಸೌಮ್ಯತೆ, ನಾಚಿಕೆ ಮತ್ತು ಸ್ಥಿರತೆ.

ಮುಖ್ಯ ಬೋಧನೆ

  1. ದಯೆ ಎಂದರೆ ಇತರರು ದುಃಖದಲ್ಲಿರುವಾಗ ಅವರಿಗೆ ಸಹಾಯ ಮಾಡಲು ಬಯಸುವುದು.
  2. ನಾವು ಇತರರಿಗೆ ದಯೆ ತೋರಿಸಿದಾಗ, ನಮ್ಮ ಹೃದಯವೂ ಸಂತೋಷದಿಂದ ತುಂಬುತ್ತದೆ.
  3. ಚಿಕ್ಕ ಸಹಾಯವೂ ದೊಡ್ಡ ವ್ಯತ್ಯಾಸ ಮಾಡಬಹುದು ಮತ್ತು ಇತರರನ್ನು ಸಂತೋಷಪಡಿಸಬಹುದು.

ಐದು-ನಿಮಿಷ ಪರಿಚಯ

ಮಕ್ಕಳೇ, ಇಂದು ನಾವು 'ದಯೆ' ಬಗ್ಗೆ ಕಲಿಯುತ್ತೇವೆ. ನಿಮ್ಮಲ್ಲಿ ಯಾರಾದರೂ ಯಾರಿಗಾದರೂ ಸಹಾಯ ಮಾಡಿದ್ದೀರಾ? [ಮಕ್ಕಳ ಉತ್ತರಗಳನ್ನು ಕೇಳಿ] ಅದ್ಭುತ! ಯಾರಾದರೂ ದುಃಖದಲ್ಲಿರುವಾಗ ಅವರಿಗೆ ಸಹಾಯ ಮಾಡಲು ಬಯಸುವ ಭಾವನೆಯೇ ದಯೆ. ಇಂದು ನಾವು ಕೃಷ್ಣನ ಮತ್ತು ಆರವ್ ಅನ ಕಥೆಗಳ ಮೂಲಕ ದಯೆ ಹೇಗೆ ತೋರಿಸಬೇಕು ಎಂದು ಕಲಿಯುತ್ತೇವೆ. ನಿಮ್ಮ ಕಣ್ಣುಗಳನ್ನು ಮುಚ್ಚಿ 'ದಯಾ' ಎಂದು ಮೂರು ಬಾರಿ ಹೇಳಿ ಮತ್ತು ನಿಮ್ಮ ಹೃದಯದ ಮೇಲೆ ಕೈ ಇಟ್ಟುಕೊಳ್ಳಿ.

40-ನಿಮಿಷ ಪಾಠ ಯೋಜನೆ

40-ನಿಮಿಷ ಪಾಠ ಯೋಜನೆ

ಪರಿಚಯ (5 ನಿಮಿ) → ಶ್ಲೋಕ ಮತ್ತು ವ್ಯಾಖ್ಯಾನ (5 ನಿಮಿ) → ಕೃಷ್ಣನ ಕಥೆ (8 ನಿಮಿ) → ಆರವ್ ಅನ ಕಥೆ (8 ನಿಮಿ) → ಚರ್ಚೆ (7 ನಿಮಿ) → ಕಾರ್ಯಪತ್ರದ ಆಟ (5 ನಿಮಿ) → ಮುಕ್ತಾಯ (2 ನಿಮಿ)

ಎರಡು-ಗಂಟೆ ಪಾಠ ಯೋಜನೆ

ಪರಿಚಯ ಮತ್ತು ವೃತ್ತ ಸಮಯ (15 ನಿಮಿ) → ಶ್ಲೋಕ ಕಲಿಕೆ ಮತ್ತು ಅರ್ಥ (15 ನಿಮಿ) → ಕೃಷ್ಣನ ಕಥೆ ಮತ್ತು ಚರ್ಚೆ (20 ನಿಮಿ) → ವಿರಾಮ (10 ನಿಮಿ) → ಆರವ್ ಅನ ಕಥೆ ಮತ್ತು ಚರ್ಚೆ (20 ನಿಮಿ) → ದಯೆಯ ಹೃದಯ ಕರಕುಶಲ (25 ನಿಮಿ) → ಸಹಾಯ ಮಾಡುವ ಕೈಗಳ ಆಟ (10 ನಿಮಿ) → ಮುಕ್ತಾಯ ವೃತ್ತ ಮತ್ತು ಪ್ರತಿಜ್ಞೆ (5 ನಿಮಿ)

ಚರ್ಚಾ ಮಾರ್ಗದರ್ಶಿ

1. ಪ್ರಶ್ನೆ: ಕೃಷ್ಣನು ಪಕ್ಷಿಯನ್ನು ಸಹಾಯ ಮಾಡಿದಾಗ ಅವನಿಗೆ ಹೇಗೆ ಅನಿಸಿರಬಹುದು? ಮಾದರಿ ಉತ್ತರ: ಅವನಿಗೆ ಸಂತೋಷವಾಗಿರಬಹುದು ಏಕೆಂದರೆ ಅವನು ಪಕ್ಷಿಯನ್ನು ಅದರ ತಾಯಿಯ ಬಳಿಗೆ ಸೇರಿಸಿದನು. 2. ಪ್ರಶ್ನೆ: ಆರವ್ ಏಕೆ ತನ್ನ ಊಟದ ಹಣವನ್ನು ನಾಯಿಮರಿಗೆ ಕೊಟ್ಟನು? ಮಾದರಿ ಉತ್ತರ: ಏಕೆಂದರೆ ಅವನ ಹೃದಯದಲ್ಲಿ ದಯೆ ಇತ್ತು ಮತ್ತು ನಾಯಿಮರಿಯ ಹಸಿವನ್ನು ನೋಡಿ ಅವನಿಗೆ ಕಷ್ಟವಾಯಿತು. 3. ಪ್ರಶ್ನೆ: ನೀವು ಯಾವಾಗ ದಯೆ ತೋರಿಸಬಹುದು? ಮಾದರಿ ಉತ್ತರ: ಯಾರಾದರೂ ಅಳುತ್ತಿರುವಾಗ, ಪ್ರಾಣಿಗಳಿಗೆ ಆಹಾರ ಕೊಡುವಾಗ, ಸ್ನೇಹಿತರಿಗೆ ಸಹಾಯ ಮಾಡುವಾಗ. ಗುಂಪು ಚರ್ಚೆ: ಮಕ್ಕಳನ್ನು ಜೋಡಿಯಾಗಿ ಕೂರಿಸಿ ಮತ್ತು ಅವರು ಹೇಗೆ ದಯೆ ತೋರಿಸಬಹುದು ಎಂದು ಚರ್ಚಿಸಲು ಹೇಳಿ.

ಸಾಮಾನ್ಯ ತಪ್ಪು ಗ್ರಹಿಕೆಗಳು

  • ತಪ್ಪು ಕಲ್ಪನೆ: ದಯೆ ತೋರಿಸುವುದು ದುರ್ಬಲತೆ ಎಂದು ಮಕ್ಕಳು ಭಾವಿಸುತ್ತಾರೆ. ಪ್ರತಿಕ್ರಿಯೆ: ದಯೆ ತೋರಿಸುವುದು ನಿಜವಾದ ಶಕ್ತಿ ಮತ್ತು ಧೈರ್ಯ. ಇತರರಿಗೆ ಸಹಾಯ ಮಾಡಲು ದೊಡ್ಡ ಹೃದಯ ಬೇಕು.
  • ತಪ್ಪು ಕಲ್ಪನೆ: ದಯೆ ಎಂದರೆ ಯಾವಾಗಲೂ 'ಹೌದು' ಎಂದು ಹೇಳುವುದು. ಪ್ರತಿಕ್ರಿಯೆ: ಕೆಲವೊಮ್ಮೆ ದಯೆ ಎಂದರೆ ಇತರರಿಗೆ ಸರಿಯಾದ ಕೆಲಸ ಮಾಡಲು ಸಹಾಯ ಮಾಡುವುದು, ಅದು 'ಇಲ್ಲ' ಎಂದು ಹೇಳುವುದನ್ನೂ ಒಳಗೊಳ್ಳಬಹುದು.
  • ತಪ್ಪು ಕಲ್ಪನೆ: ದಯೆ ಕೇವಲ ಮನುಷ್ಯರಿಗೆ ಮಾತ್ರ ತೋರಿಸಬೇಕು. ಪ್ರತಿಕ್ರಿಯೆ: ದಯೆ ಎಲ್ಲಾ ಜೀವಿಗಳಿಗೆ - ಪ್ರಾಣಿಗಳು, ಪಕ್ಷಿಗಳು, ಮರಗಳಿಗೂ ತೋರಿಸಬೇಕು.
