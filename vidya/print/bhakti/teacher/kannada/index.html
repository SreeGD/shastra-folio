ಅಧ್ಯಾಯ ಪರಿಚಯ

ಭಕ್ತಿ ಎಂದರೆ ಪೂರ್ಣ ಹೃದಯದಿಂದ ದೇವರನ್ನು ಪ್ರೀತಿಸುವುದು. ನಿಮ್ಮ ಆತ್ಮೀಯ ಸ್ನೇಹಿತನನ್ನು ಕಾಳಜಿ ವಹಿಸುವಂತೆ ಕೃಷ್ಣನನ್ನು ಕಾಳಜಿ ವಹಿಸುವುದು. ಭಕ್ತಿ ಇರುವಾಗ ನೀವು ಕೃಷ್ಣನನ್ನು ಸಂತೋಷಪಡಿಸಲು ಬಯಸುತ್ತೀರಿ.

ಶ್ಲೋಕ: Bhagavad-gita 9.34 — ಯಾವಾಗಲೂ ನನ್ನನ್ನು ಸ್ಮರಿಸು. ನನ್ನನ್ನು ಪ್ರೀತಿಸು. ನನ್ನನ್ನು ಪೂಜಿಸು. ನನಗೆ ನಮಸ್ಕರಿಸು. ಹೀಗೆ ಮಾಡಿದರೆ ನೀನು ನನ್ನನ್ನು ಹೊಂದುವೆ.

ಮುಖ್ಯ ಬೋಧನೆ

  1. ಪ್ರೀತಿ ಎಂದರೆ ಕೊಡುವುದು, ಕೇವಲ ತೆಗೆದುಕೊಳ್ಳುವುದಲ್ಲ. ಇತರರೊಂದಿಗೆ ಹಂಚಿಕೊಂಡಾಗ ನಮ್ಮ ಹೃದಯ ಸಂತೋಷಪಡುತ್ತದೆ.
  2. ನಾವು ಇತರರನ್ನು ಪ್ರೀತಿಸಿದಾಗ ದೇವರು ನಮ್ಮನ್ನು ಪ್ರೀತಿಸುತ್ತಾರೆ. ಜನರೊಂದಿಗೆ ಮತ್ತು ಪ್ರಾಣಿಗಳೊಂದಿಗೆ ಕರುಣೆ ತೋರಿಸುವುದು ದೇವರನ್ನು ಸಂತೋಷಪಡಿಸುತ್ತದೆ.
  3. ಪ್ರೀತಿಯಿಂದ ಕೊಡುವ ಚಿಕ್ಕ ಉಡುಗೊರೆಯು ಕಾಳಜಿಯಿಲ್ಲದೆ ಕೊಡುವ ದೊಡ್ಡ ಉಡುಗೊರೆಗಿಂತ ಅಮೂಲ್ಯ.

ಐದು-ನಿಮಿಷ ಪರಿಚಯ

ಮಕ್ಕಳನ್ನು ಕೇಳಿ: 'ನಿಮ್ಮ ಕುಟುಂಬದಲ್ಲಿ ಯಾರನ್ನು ಅತಿ ಹೆಚ್ಚು ಪ್ರೀತಿಸುತ್ತೀರಿ?' ಅವರು ಹಂಚಿಕೊಳ್ಳಲಿ. ನಂತರ ಹೇಳಿ: 'ಇಂದು ನಾವು ಭಕ್ತಿ ಎಂಬ ವಿಶೇಷ ಪ್ರೀತಿಯ ಬಗ್ಗೆ ಕಲಿಯುತ್ತೇವೆ — ದೇವರನ್ನು ಪ್ರೀತಿಸುವುದು ಮತ್ತು ಆ ಪ್ರೀತಿಯನ್ನು ಸುತ್ತಲಿನ ಎಲ್ಲ ಜೀವಿಗಳಿಗೆ ಕರುಣೆಯ ಮೂಲಕ ತೋರಿಸುವುದು.'

40-ನಿಮಿಷ ಪಾಠ ಯೋಜನೆ

40-ನಿಮಿಷ ಪಾಠ ಯೋಜನೆ

ಪರಿಚಯ (5 ನಿ) → ಕನಕದಾಸ ಕಥೆ (10 ನಿ) → ಅನುಷ್ಕಾ ಕಥೆ (8 ನಿ) → ಚರ್ಚೆ (8 ನಿ) → ಕಿಂಡಿ ಕಲೆ (9 ನಿ)

ಎರಡು-ಗಂಟೆ ಪಾಠ ಯೋಜನೆ

ಪರಿಚಯ (10 ನಿ) → ಕನಕದಾಸ ಕಥೆ ನಾಟಕದೊಂದಿಗೆ (25 ನಿ) → ಅನುಷ್ಕಾ ಕಥೆ + ಚರ್ಚೆ (20 ನಿ) → ಕಿಂಡಿ ಕಲೆ (30 ನಿ) → ಜಗದೋದ್ಧಾರನ ಹಾಡು (20 ನಿ) → ಪೂಜಾ ಸ್ಥಳ ಸ್ವಚ್ಛಗೊಳಿಸುವ ಸೇವೆ (10 ನಿ) → ಮುಕ್ತಾಯ (5 ನಿ)

ಚರ್ಚಾ ಮಾರ್ಗದರ್ಶಿ

1. ಕೃಷ್ಣ ಏಕೆ ಕನಕದಾಸನಿಗಾಗಿ ತಿರುಗಿದರು? 2. ಅನುಷ್ಕಾ ಕೃಷ್ಣನಿಗೆ ಯಾವ ಸೇವೆ ಮಾಡಿದಳು? 3. ನಾವು ಮನೆಯಲ್ಲಿ ಪ್ರತಿದಿನ ಭಕ್ತಿಯನ್ನು ಹೇಗೆ ತೋರಿಸಬಹುದು?

ಸಾಮಾನ್ಯ ತಪ್ಪು ಗ್ರಹಿಕೆಗಳು

  • ತಪ್ಪು ಕಲ್ಪನೆ: ಭಕ್ತಿ ಎಂದರೆ ದೇವಾಲಯದಲ್ಲಿ ಮಾತ್ರ ಪ್ರಾರ್ಥಿಸುವುದು ಎಂದು ಮಕ್ಕಳು ಭಾವಿಸುತ್ತಾರೆ. ಉತ್ತರ: ಪ್ರಾಣಿಗಳಿಗೆ ಕರುಣೆ, ಸ್ನೇಹಿತರೊಂದಿಗೆ ಹಂಚಿಕೆ, ಮನೆಯಲ್ಲಿ ಸಹಾಯ — ಇವೆಲ್ಲ ಭಕ್ತಿಯ ರೂಪಗಳೇ.
  • ತಪ್ಪು ಕಲ್ಪನೆ: ಭಕ್ತಿ ತೋರಿಸಲು ಜಾತಿ ಅಥವಾ ಸಂಪತ್ತು ಬೇಕು. ಉತ್ತರ: ಕನಕದಾಸನ ಕಥೆಯಲ್ಲಿ ಕೃಷ್ಣ ಜಾತಿ ನೋಡಲಿಲ್ಲ — ಕೇವಲ ಹೃದಯ ನೋಡಿದರು.
